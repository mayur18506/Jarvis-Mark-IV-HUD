# 🤖 J.A.R.V.I.S. Mark IV - AI-Powered Full-Stack Desktop Assistant

A voice-controlled, Tony Stark-inspired virtual assistant built as a custom desktop operating interface. It features a sci-fi React HUD, an enterprise-grade C# ASP.NET Core backend for system/local OS commands, and Google Gemini AI integration.

## 🚀 Tech Stack
* **Frontend:** React.js, JavaScript, HTML5 Web Speech API, CSS (Sci-Fi HUD layout)
* **Backend:** C#, ASP.NET Core Minimal APIs, Windows Native integration
* **AI & Logic:** Google Gemini LLM API + Custom Smart Offline Fallback Engine

## ✨ Key Features
* **Real-time Telemetry:** Monitors system status and controls local processes.
* **Voice Command Pipeline:** Continuous listening mode for hands-free operations.
* **Local OS Automation:** Instantly launches applications (VS Code, GitHub, Notepad) and retrieves local info (exact system time).
* **Hybrid Architecture:** Seamlessly switches between Gemini Cloud AI and local smart replies to ensure zero downtime.
